# PDF 파일 암호화 솔루션 (pdf-encryption)

본 애플리케이션은 분할 완료된 개인별 급여명세서 PDF 파일의 개인정보 보안을 위해, 사용자의 로컬 환경 내에서 안전하게 개별 비밀번호를 설정하고 덮어쓰기 암호화를 적용하는 프리미엄 Pure 프론트엔드 솔루션입니다.

## 아키텍처 및 보안 설계
- **100% Pure 클라이언트 사이드**: 로컬 브라우저 내에서만 안전하게 동작하여 어떠한 개인정보나 PDF 바이너리 파일도 외부 서버로 전송하지 않습니다. (개인정보 보호법 완전 준수)
- **로컬 디렉토리 직접 I/O (File System Access API)**: `showDirectoryPicker`를 활용해 대상 디렉토리에 접근하여 브라우저 샌드박스 보안 한계를 뛰어넘는 고성능 읽기/쓰기를 구현합니다.
- **가벼운 PDF 암호화 엔진**: `@pdfsmaller/pdf-encrypt-lite` 라이브러리를 CDN의 ES Module 형식을 활용해 동적으로 로드함으로써, 파일 손상 없이 고속으로 강력한 RC4 128비트 암호화를 적용합니다.

## 핵심 기능 요구사항 및 UI/UX 디자인

### 1. 로컬 폴더 보안 연동 및 파일 자동 탐색
- 사용자가 **[📁 로컬 폴더 찾기]** 버튼을 클릭하여 작업 대상 폴더를 연동합니다.
- 읽기/쓰기 권한(`readwrite`) 승인 직후, 해당 폴더 내에 존재하는 모든 `.pdf` 확장자 파일들만 실시간으로 탐색하여 목록 테이블을 생성합니다.
- 보안 연동 완료 시, 사용자의 업무 인지 편의를 위해 대상 폴더명 및 실제 절대 가상 경로(`📁 로컬 보안 폴더: /Users/dychae/급여명세서_Project/...`)를 가독성 높은 디자인으로 상단에 시각화합니다.

### 2. 고정밀 일괄 적용 및 개별 비밀번호 설정 폼
- **일괄 패스워드 적용 (업무 편의)**: 많은 양의 PDF 파일에 공통 비밀번호를 빠르게 설정해야 하는 관리자를 위해, 상단 패스워드 폼에 값을 입력한 후 `🔑 선택 목록에 일괄 적용` 버튼을 클릭하면 체크된 모든 파일 입력칸에 패스워드가 동시에 주입됩니다.
- **개별 비밀번호 제어**: 파일 리스트의 각 행 우측에 개별 패스워드 입력 박스가 배치되어, 직원별 고유 비밀번호(예: 생년월일, 주민번호 뒷자리)를 자유롭게 개별 지정할 수 있습니다.
- **눈동자 토글 (Visibility Toggle)**: 일괄 입력칸 및 개별 입력칸 우측에 눈동자 아이콘 버튼을 배치하여 비밀번호의 표시(text) 및 숨김(password) 상태를 부드러운 반응형으로 언제든 전환할 수 있습니다.

### 3. 실시간 선택 및 순차 덮어쓰기 암호화 파이프라인
- **다중 선택 제어**: 테이블 제목 라인의 `전체 선택` 체크박스 및 개별 체크박스를 연동하여 암호화를 진행할 파일들만 선별적으로 조작합니다.
- **순차 비동기 암호화 루프**: `암호화 시작` 버튼 클릭 시 체크된 대상을 선별하여 순차적으로 비동기 암호화를 시작합니다.
- **다이렉트 원본 덮어쓰기**: 암호화가 완료된 Uint8Array 바이너리를 브라우저 임시 다운로드 창으로 띄우지 않고, 원본 파일 핸들의 `createWritable()` 스트림에 1:1로 다이렉트 덮어쓰기하여 업무 처리 속도를 극대화합니다.
- **실시간 상태 배지**: 각 파일 행의 우측 상태 칼럼에 실시간으로 진행 상태에 맞춘 배지 디자인(대기: 그레이 `대기 중`, 진행중: 블루 펄스 `암호화 중...`, 성공: 에메랄드 `🎉 암호화 성공`, 실패: 레드 `❌ 실패: 사유`)을 렌더링합니다.

## 성능 및 예외 처리 기술 노하우
- **오류 격리 및 루프 완주**: 개별 PDF 파일에 비밀번호가 누락되었거나, 파일 손상 또는 OS 수준의 디스크 I/O 락이 발생하더라도 전체 암호화 프로세스가 끊기지 않고 해당 행만 `실패` 배지로 처리된 후 다음 파일로 즉시 안전하게 넘어갑니다.
- **RequestAnimationFrame 양보**: 고용량 대량 PDF 파일 암호화 시 브라우저가 응답 없음 상태에 빠지는 문제를 원천 차단하기 위해, 각 파일 작업 주기마다 `requestAnimationFrame`을 통해 UI 렌더링 스레드에 제어권을 양보하여 실시간 프로그레스 바와 성공률 수치가 60fps로 매끄럽게 갱신되도록 처리합니다.
